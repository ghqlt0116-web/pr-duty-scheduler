# PR팀 가판 당직 스케줄러

## 배포 방법 (Vercel + GitHub)

1. 이 폴더를 GitHub 저장소로 업로드
2. [vercel.com](https://vercel.com) 접속 → GitHub 연동 → 저장소 선택 → Deploy
3. 생성된 URL을 팀에 공유

## 기능
- 월별 당직 스케줄 자동 생성 (순번 기준)
- 연속당직 ⚠ 자동 표시
- 담당자가 특정 날짜 수기 수정 가능
- 수정 내용 localStorage에 저장 (새로고침 유지)
- 인원 추가/삭제, 부재 기간 등록
